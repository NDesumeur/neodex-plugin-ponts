# Ponts

Relie toutes les îles par des ponts droits, un ou deux entre deux îles, sans croisement. Le chiffre de chaque île dit combien de ponts en partent.

Chaque archipel est généré. Glisse d'une île vers une voisine en ligne droite pour poser un pont, puis un deuxième, puis aucun. Toute solution qui respecte les chiffres, sans croisement et d'un seul tenant, est acceptée.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Ponts → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
